v1.5.0 - 全站动森风格重设计与灵感仓库

2026年7月24日

新增功能

  • 灵感仓库 — 新增「灵感仓库」导航模块，支持文章列表浏览与详情钻入
  • 文章数据通过 articles/index.json 动态加载，支持搜索过滤

全站 UI 重设计

  • 整体风格从苹果风切换为动物森友会（Animal Island）风格
  • 引入 Nunito + Noto Sans SC 圆体字体组合
  • 配色方案：奶油米白背景 + 温暖大地棕文字 + 薄荷青绿主色
  • 深色主题调整为暖夜森林色调，告别冷灰黑

视觉细节优化

  • 工具卡片新增飘带标题（swallowtail ribbon），5 色轮换增加活泼感
  • 侧边栏改为游戏机菜单风格，选中态为实心青绿胶囊
  • 卡片采用奶油底 + 圆角 + 边框分层，hover 上浮替代阴影
  • 返回按钮改为 pill 形描边，返回顶部按钮增加 3D 立体按键感
  • 搜索框焦点使用薄荷青绿细环，全局焦点环改为黄色
  • 首页背景渐变为暖橙色调

参考项目

  • 新增 animal-island-ui 参考项目，包含完整组件库与设计 token
